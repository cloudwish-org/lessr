# Base pack

Twenty signed declarative rules covering the commands that produce most tool-output tokens. Format and signing: ../../docs/PACKS.md.

Planned rules: git-status, git-diff, git-log, git-push, cargo-test, cargo-build, cargo-clippy, npm-test, npm-install, npm-run, pnpm-install, pytest, go-test, ls-tree, grep-rg, cat-head, docker-ps, docker-logs, ruff, eslint-tsc.
